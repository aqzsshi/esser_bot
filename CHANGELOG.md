# Журнал изменений

## Версия 2.0.0 - Модуль отчетности результатов игр

### 🆕 Новые функции
- **Модуль отчетности результатов игр** для World of Tanks
- **Команда `/вс`** - отправка отчетов о результатах игр
- **Команда `/вс_настройка`** - настройка модуля (только для администраторов)
- **31 карта** World of Tanks, разбитая на 3 категории
- **Мультисерверность** - каждый сервер имеет свои настройки
- **Embed сообщения** с разными фото для победы и поражения

### 🔧 Исправления
1. **TypeError: require(...) is not a function**
   - Убрана проблемная строка из `index.js`
   - Модуль теперь загружается автоматически через `slashCommands.js`

2. **ExpectedConstraintError: Invalid number value**
   - Discord.js ограничение: максимум 25 опций в StringSelectMenu
   - Карты разбиты на категории (≤25 карт в каждой)
   - Улучшен пользовательский интерфейс

3. **Warning: "ephemeral" is deprecated**
   - Заменен на `flags: 64` во всех командах
   - Совместимость с новыми версиями Discord.js

### ✨ Новые улучшения
- **Карусель игроков**: Красивый выбор игроков из списка участников
- **Большие фото снизу**: Фото отображаются крупно под текстом
- **Множественный выбор**: Возможность выбрать до 10 игроков одновременно
- **Фильтрация по ролям**: Показываются только участники с разрешенными ролями
- **Категории карт**: Логичная группировка по типам (Классические, Современные, Европейские)
- **Улучшенный UI**: Более логичная и удобная навигация

### 🎯 Как использовать
1. **Администратор** настраивает модуль: `/вс_настройка`
2. **Игроки** отправляют отчеты: `/вс`
3. Результаты автоматически отправляются в настроенный канал
