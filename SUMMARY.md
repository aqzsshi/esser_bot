# Краткая сводка изменений

## 🎯 Что было реализовано

### ✅ Основной функционал
- **Модуль отчетности результатов игр** для World of Tanks
- **Команда `/вс`** - отправка отчетов о результатах игр
- **Команда `/вс_настройка`** - настройка модуля (только для администраторов)
- **31 карта** World of Tanks, разбитая на 3 категории
- **Мультисерверность** - каждый сервер имеет свои настройки

### 🗺️ Структура карт
- **🏛️ Классические карты** (10 карт)
- **🏙️ Современные карты** (10 карт)
- **🌍 Европейские карты** (11 карт)

### 👥 Выбор игроков
- **Карусель участников** вместо ручного ввода
- **Множественный выбор** (от 1 до 10 игроков)
- **Автоматический список** всех участников сервера
- **Сортировка по алфавиту** для удобства

### 🖼️ Отображение фото
- **Большие фото снизу** (setImage) вместо маленьких сбоку
- **Разные фото** для победы и поражения
- **Красивые embed сообщения** с полной информацией

## 🚀 Как использовать

### Для администраторов:
```
/вс_настройка канал:#отчеты фото_победы:ссылка фото_поражения:ссылка
```

### Для игроков:
1. `/вс` - начать создание отчета
2. Выбрать категорию карт
3. Выбрать конкретную карту
4. Выбрать результат (Победа/Поражение)
5. Выбрать игроков из карусели
6. Отчет автоматически отправляется в настроенный канал
