# Устранение ошибок

## Ошибка: TypeError: require(...) is not a function

### Причина
Эта ошибка возникала из-за неправильного подключения модуля `gameResultsHandler` в `index.js`.

### Решение ✅
Проблема уже исправлена! Модуль `gameResultsHandler` теперь загружается автоматически через систему команд `slashCommands.js`.

### Что было исправлено
1. Убрана строка `require('./handlers/gameResultsHandler')(client);` из `index.js`
2. Модуль теперь загружается автоматически при запуске бота
3. Команды `/вс` и `/вс_настройка` регистрируются автоматически

## Ошибка: ExpectedConstraintError > s.number().lessThanOrEqual() Invalid number value

### Причина
Discord.js имеет ограничение на количество опций в StringSelectMenu - максимум 25, а у нас было 31 карта.

### Решение ✅
Карты разбиты на 3 категории, каждая содержит не более 25 карт:
- 🏛️ Классические карты (10 карт)
- 🏙️ Современные карты (10 карт)  
- 🌍 Европейские карты (11 карт)

### Что было исправлено
1. Изменена структура выбора карт: сначала категория, потом карта
2. Каждая категория содержит ≤25 карт (в пределах лимита Discord.js)
3. Улучшен пользовательский интерфейс с логичной группировкой

## Предупреждения

### Warning: Supplying "ephemeral" for interaction response options is deprecated

**Причина**: В новых версиях Discord.js параметр `ephemeral` устарел.

**Решение ✅**: Заменен на `flags: 64` во всех командах модуля.

## Возможные проблемы

### 1. Неверный токен Discord
```
Error [TokenInvalid]: An invalid token was provided.
```
**Решение**: Проверьте токен в `config.json` или переменной окружения `DISCORD_TOKEN`

### 2. Отсутствуют зависимости
```
Cannot find module 'discord.js'
```
**Решение**: Выполните `npm install`

### 3. Неправильные права бота
```
Missing Permissions
```
**Решение**: Убедитесь, что бот имеет необходимые права на сервере
