# Устранение ошибок

## Ошибка: TypeError: require(...) is not a function

### Причина
Эта ошибка возникала из-за неправильного подключения модуля `gameResultsHandler` в `index.js`.

### Решение ✅
Проблема уже исправлена! Модуль `gameResultsHandler` теперь загружается автоматически через систему команд `slashCommands.js`.

### Что было исправлено
1. Убрана строка `require('./handlers/gameResultsHandler')(client);` из `index.js`
2. Модуль теперь загружается автоматически при запуске бота
3. Команды `/вс` и `/вс_настройка` регистрируются автоматически

## Возможные проблемы

### 1. Неверный токен Discord
```
Error [TokenInvalid]: An invalid token was provided.
```
**Решение**: Проверьте токен в `config.json` или переменной окружения `DISCORD_TOKEN`

### 2. Отсутствуют зависимости
```
Cannot find module 'discord.js'
```
**Решение**: Выполните `npm install`

### 3. Неправильные права бота
```
Missing Permissions
```
**Решение**: Убедитесь, что бот имеет необходимые права на сервере
