# Модуль отчетности результатов игр (World of Tanks)

## Описание
Этот модуль позволяет игрокам отправлять отчеты о результатах игр на различных картах World of Tanks. Модуль автоматически ведет учет результатов для каждого сервера отдельно.

## Команды

### `/вс`
- **Описание**: Отчет о результате игры на карте
- **Доступ**: Все пользователи (после настройки модуля)
- **Функционал**: 
  1. Показывает карусель с 30+ картами для выбора
  2. После выбора карты предлагает выбрать результат (Победа/Поражение)
  3. Отправляет embed сообщение в настроенный канал

### `/вс_настройка`
- **Описание**: Настройка модуля отчетности результатов игр
- **Доступ**: Только администраторы сервера
- **Параметры**:
  - `канал` - Канал для отправки отчетов о результатах игр
  - `фото_победы` - Ссылка на фото для победы
  - `фото_поражения` - Ссылка на фото для поражения

## Настройка

### Для администраторов сервера:

1. Используйте команду `/вс_настройка`
2. Укажите канал, куда будут отправляться отчеты
3. Укажите ссылки на фото для победы и поражения
4. Модуль автоматически сохранит настройки для вашего сервера

### Пример настройки:
```
/вс_настройка канал:#отчеты-игр фото_победы:https://example.com/win.png фото_поражения:https://example.com/lose.png
```

## Использование

### Для игроков:

1. Используйте команду `/вс`
2. Выберите группу карт (Карты 1-16 или Карты 17-31)
3. Выберите конкретную карту из выбранной группы
4. Выберите результат игры (🏆 Победа или 💀 Поражение)
5. **Выберите игроков из карусели** (можно выбрать несколько)
6. Отчет автоматически отправится в настроенный канал с **большим фото снизу**

## Особенности

- **Мультисерверность**: Каждый сервер имеет свои настройки
- **Безопасность**: Только администраторы могут настраивать модуль
- **Автоматический учет**: Результаты автоматически сохраняются с датой и временем
- **Красивые embed сообщения**: Результаты отображаются в стильных embed сообщениях
- **Большие фото снизу**: Изображения отображаются крупно под текстом
- **Карусель игроков**: Удобный выбор нескольких игроков из списка участников
- **Улучшенный интерфейс**: Простая группировка карт по номерам
- **Автоматический список**: Показывает всех участников сервера для выбора

- Права администратора для настройки
- Настроенный канал для отчетов
- Валидные ссылки на изображения (http/https)
